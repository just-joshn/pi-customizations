# Benny for Pi

This pack contains dormant setup and operational instructions. It is not a public Pi skill collection.

For a packaged setup, read `host/adapters/benny/SKILL.md` in pi-pstack. After installation, read `skills/setup-benny/SKILL.md` in this pack. Use the native setup helper to merge the pack into `.pi/automations/benny` and its explicit shared dependencies into `.pi/skills`.

Keep configuration, feature maps, and routing maps in `.pi/benny` or another user-owned location outside this pack. Review conflicts before refreshing managed files. Commit the pack, project dependencies, and referenced secret-free configuration before enabling either workflow.

A configured trusted Slack trigger adapter and approved Pi routine revisions are required. Installation does not activate them.
