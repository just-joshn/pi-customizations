Details are in `cli/report.md`, `customization/report.md`, and `services/report.md`.

Important distinctions include one-message skill attachment versus sticky Custom Modes, foreground versus background tasks, notification methods versus blocking requests, and accepted webhook delivery versus completed work. ## Gotchas and unresolved decisions

Keep contradictory claims open rather than selecting the easier assertion.

- CLI force and write behavior, interactive trust, pool idle defaults, and pool syntax conflict across inspected documents.
- Agent frontmatter requirements and hook merge priority need context-sensitive reconciliation.
- Cloud capabilities exclude SSE and `mcp-remote`, while API creation prose accepts additional transports. Local MCP transport support is another context.
- Automation help describes a shared service account, while the reference describes dedicated accounts and migration on save.
- Pstack routine navigation differs from current help navigation.
- Public write-only secret behavior cannot justify exposing a value to the model to satisfy the plugin's credential-file instruction.
- Historical changelog entries are not automatically current defaults. The graph marks their version applicability unresolved.
- The customization partition left its run-mode capture unread. The coordinator read a matching service capture completely. Root queue reconciliation records this without changing the original reader's receipt.

Maintain three separate evidence states.

1. A missing public contract means a document, builtin body, or schema has not been located or resolved. Page not found does not prove feature absence.
2. A missing working service means the successful branch is inaccessible or has no operational evidence. The parent progress records a usage-limit failure, but this task neither reproduced it nor demonstrated successful service operation.
3. A legitimate unavailable-service failure is a required negative case under its own conditions. It cannot substitute for working-service evidence.

No model-backed Cursor journey, installation, automation activation, routine activation, publication, deployment, spending change, secret read, or external communication occurred. Read-only public HTTP retrieval was the only external action.
