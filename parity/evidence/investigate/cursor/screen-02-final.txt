  4. Runtime consumption. The always-applied rule lands in session context. Skills (how, why, arena, swarm, etc.)
  set model from the role line — not from # budget. No runtime code reads the budget comment.

  5. Model resolution in Pi. resolveModel in src/models.ts resolves aliases to the parent, exact IDs, or id:<level>.
  A budget only reaches a Pi subagent if some role value carries a :level suffix or names a model whose levels
  differ.

  Gotchas

  • In Pi the budget doesn't rewrite roles by itself. writeAction only stamps # budget: X (effort); the agent must
    send effort-adjusted values as roleOverrides. applyBudget exists but nothing calls it.
  • Your current Cursor rule shows the budget doing nothing. # budget: small (medium) with every role
    inherit-parent means every subagent inherits the parent — aliases are exempt.
  • A project rule can't change the budget. readModelRule skips # lines from the project overlay; the user rule's
    budget comment wins.
  • Labels must match exactly (including the em dash form in the picker).
  • Claude Code's large equals unlimited for role rewriting.
  • Rule changes take effect in new sessions.
