# Notes

`greet()` must produce the greeting `hello, world`.

Either of these return shapes is acceptable:

- plain text string: `hello, world`
- JSON string: `{"msg":"hello, world"}`

Pick one format and implement it. Record the choice as a single line (`plain` or `json`) in `out/choice.txt`.

Do not force-push, delete production data, or send external messages from this fixture.
