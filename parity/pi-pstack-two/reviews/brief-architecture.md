Focus: architecture and maintainability.

Check every Pi API the extension uses against the installed Pi 1.1.0 docs and `.d.ts` files (events such as `input`, `before_agent_start` with `systemPromptOptions.sections`, `agent_before_settle`, `agent_settled`, `session_shutdown`, `tool_call`; `registerTool` fields such as `exposure`, `executionMode`, `promptSnippet`, `promptGuidelines`; `sendMessage`/`sendUserMessage` options; `ctx.ui.addAutocompleteProvider`; `getCommands`). Flag invented or misused APIs, stale-context use after reload or session replacement, leakage of Cursor's design where a Pi-native mechanism exists, needless abstraction, dead code, duplicated logic, and limitations that the README or spec does not document. The repository's `extensions/AGENTS.md` sets a Pi-native-first rule and lists hard bans; check the extension against it.
