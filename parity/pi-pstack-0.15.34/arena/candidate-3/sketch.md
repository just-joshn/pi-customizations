## Core types

```ts
/** Registry pin. Single source of truth for which upstream release we vendor. */
export type SourcePin = {
  repository: 'https://github.com/cursor/plugins';
  commit: string; // full sha; for this move: 164ced10fa576ddf91e1f03b4fa9d1183c8272fe
  pstackVersion: string; // '0.15.34'
  teamKitVersion: string; // '1.2.0'
};

/**
 * Upstream source paths that match the pstack tree pattern but must not ship.
 * Declared next to SOURCE so exclusion is structural, not a post-sync delete.
 * Invariant: every pattern is anchored to a known non-runtime fixture tree.
 */
export type ExcludePattern = RegExp;

export type SourceEntry = {
  mode: string; // git ls-tree mode, e.g. '100644' | '100755'
  source: string; // path inside cursor/plugins, e.g. 'pstack/skills/…'
};

export type TransformKind = 'none' | 'frontmatter' | `patch:${string}`;

export type PlannedFile = {
  source: string;
  target: string; // path relative to package root
  mode: string;
  bytes: Buffer;
  transform: TransformKind;
  sourceSha256: string;
  targetSha256: string;
  sourceFrontmatter?: string;
};

export type LockFile = Omit<PlannedFile, 'bytes'> & {
  // lock drops bytes; hashes remain
};

export type UpstreamLock = {
  source: SourcePin;
  files: LockFile[]; // sorted by target; never contains a source matching EXCLUDE
  authored: string[]; // e.g. ['skills/create-skill/SKILL.md']
};
```

## Verification ladder (done predicate)

Ordered; each step must PASS before the next. Encoded as the move’s acceptance procedure, not optional polish.

```
1. RED   resources pin/count tests fail against old lock
2. EDIT  SOURCE + EXCLUDE + targetFor; SCRIPT-001 + RES counts sketched
3. SYNC  bun run sync:upstream -- --source <plugins checkout at/with 164ced1>
4. GREEN bun run check:upstream — plan length lean; no scripts/test/** on disk
5. GATE  bun run typecheck && bun run test
6. LIVE  control-pi / live:e2e (or established control-pi confirm path) on real Pi surface
7. FACT  independent sha256 of every upstream.lock.json target vs disk (confirm ledger)
```

Crash/retry: sync and check are idempotent on the same SOURCE+EXCLUDE; a half-written tree is repaired by re-running sync (writePlan replaces targets and removes stale).
